# WORDS VR

RearVuez × Al3X MiX. Walk the club, watch the films, enter VR.

The last VR session for **WORDS** — rebuilt as a WebXR floor with cinema playback for:

- WORDS
- The Dance Floor Knows
- CHK N’ DKN
- Found My People

## Play

1. **Enter the floor** — drag to look, WASD or the on-screen stick to walk
2. **Cinema** — watch the complete cuts
3. **Enter VR** — Quest / PCVR browser on a live HTTPS link (headset required)

## Develop

```bash
npm install
npm run dev
```

```bash
npm run build
npm run typecheck
```
